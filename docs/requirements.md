# Requirements Ecommerce Single Vendor

## 1. Nama Aplikasi

Ecommerce Go

## 2. Deskripsi Aplikasi

Ecommerce Go adalah aplikasi toko online single vendor yang digunakan untuk menjual produk secara online.

Aplikasi ini hanya memiliki satu toko atau pemilik usaha.

Customer dapat melihat produk dan melakukan pembelian. Admin dapat mengelola produk dan pesanan.

## 3. Tujuan Aplikasi

Membuat aplikasi ecommerce sederhana yang dapat digunakan untuk:

- Menampilkan produk.
- Memudahkan customer membeli produk.
- Mengelola keranjang belanja.
- Mengelola pesanan.
- Membantu admin mengelola produk toko.

## 4. Aktor Pengguna

### Customer

Customer adalah pengguna yang membeli produk dari toko.

### Admin

Admin adalah pengguna yang mengelola produk dan pesanan toko.

## 5. Fitur Customer

Customer dapat:

- Melihat daftar produk.
- Melihat detail produk.
- Menambahkan produk ke keranjang.
- Mengubah jumlah produk di keranjang.
- Menghapus produk dari keranjang.
- Melakukan checkout.
- Membuat pesanan.
- Melihat daftar pesanan.
- Melihat detail pesanan.

## 6. Fitur Admin

Admin dapat:

- Login ke halaman admin.
- Melihat dashboard sederhana.
- Menambahkan produk.
- Melihat daftar produk.
- Mengubah data produk.
- Menghapus produk.
- Menambahkan kategori produk.
- Mengubah kategori produk.
- Menghapus kategori produk.
- Melihat daftar pesanan.
- Melihat detail pesanan.
- Mengubah status pesanan.

## 7. Batasan Aplikasi

Versi awal aplikasi hanya menggunakan satu vendor atau satu toko.

Aplikasi belum mendukung:

- Multi vendor.
- Marketplace.
- Voucher.
- Wishlist.
- Review produk.
- Rating produk.
- Chat.
- Loyalty point.
- Retur dan refund kompleks.
- Multi gudang.

## 8. Alur Utama Customer

Customer melakukan proses berikut:

1. Membuka website.
2. Melihat daftar produk.
3. Memilih produk.
4. Melihat detail produk.
5. Menambahkan produk ke keranjang.
6. Membuka keranjang.
7. Melakukan checkout.
8. Membuat pesanan.
9. Melihat status pesanan.

## 9. Alur Utama Admin

Admin melakukan proses berikut:

1. Login.
2. Membuka dashboard.
3. Mengelola kategori.
4. Mengelola produk.
5. Melihat pesanan customer.
6. Mengubah status pesanan.

## 10. Target MVP

MVP aplikasi harus mampu melakukan hal berikut:

### Customer

- Login atau register.
- Melihat produk.
- Menambahkan produk ke keranjang.
- Checkout.
- Membuat pesanan.
- Melihat pesanan.

### Admin

- Login.
- Mengelola kategori.
- Mengelola produk.
- Melihat pesanan.
- Mengubah status pesanan.
